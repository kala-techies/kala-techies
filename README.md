## 🚀 Flagship project: OfflineMoMAI

A fully offline AI meeting assistant for Android. Records or imports a meeting, transcribes it **on-device** with whisper.cpp, and generates a summary + Minutes of Meeting with an **on-device LLM** (llama.cpp, Qwen2.5-1.5B-Instruct). Includes a real-time offline speech/text translator across English and nine Indian languages. Nothing is ever uploaded — no cloud, no accounts, no login.

**What makes it hard:** running speech recognition and LLM inference entirely within a phone's memory/CPU budget, keeping generation reliable enough to demo under hard timeouts, and holding a clean Flutter/Dart architecture (domain/data/presentation, MVVM, Repository pattern) together across it all.
